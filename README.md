# APL121 — Бие даалт №1: Code Quest
## Сэдэв 19: Сагсан бөмбөгийн статистик

### Товч танилцуулга
Энэхүү программ нь n тоглогчийн 1 оноот (чөлөөт шидэлт), 2 оноот, 3 оноот шидэлтийн амжилтыг бүртгэж, нийт оноог тооцоолох, тоглогчдын ангиллыг `switch` болон `else-if` ашиглан гаргах, шилдэг тоглогчдыг эрэмбэлэх болон MVP (Хамгийн үнэ цэнэтэй тоглогч)-г олох зорилготой.

### Тогтоосон дүрмүүд ба хязгаарлалт
1. **Тоглогчийн тоо ($n$):** Бага хаясан ч 5 тоглогчийн өгөгдлөөр хүснэгт хэвлэнэ (программ дээр гараас оруулна).
2. **Тоглогчийн түвшин/Ангилал (switch / else-if):**
   - Нийт оноо $\ge 50$ байвал: **"А зэрэглэлийн тоглогч (MVP candidate)"**
   - Нийт оноо $30 - 49$ хооронд байвал: **"B зэрэглэлийн тоглогч (Starter)"**
   - Нийт оноо $20 - 29$ хооронд байвал: **"C зэрэглэлийн тоглогч (Rotation)"**
   - Нийт оноо $< 20$ байвал: **"D зэрэглэлийн тоглогч (Bench)"**
3. **Оролтын шалгалт:** Шүүгч/Ашиглагч шидэлтийн тоог сөрөг тоогоор оруулах үед `do-while` давталтаар алдаа зааж, зөв утга авах хүртэл дахин асууна.
